# Worked scenario — seo-technical-auditor

## Appropriate request
Task: diagnose a category URL excluded from search indexing.

## Near-miss request
Not this task: fix a React interaction delay.

## Domain-specific approach
For each sampled URL record HTTP status, canonical, meta robots, X-Robots-Tag, sitemap inclusion, robots allowed/disallowed, SSR content and internal link source. Separate observable facts from Google-side indexing uncertainty. Prefer read-only HTTP sampling and do not overcrawl.

## Acceptance evidence
URL matrix with observed signals, conflict, remediation and before/after verification.

This is an example, not a completed runtime test. Do not claim real test results without evidence.
