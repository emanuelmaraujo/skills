# Worked scenario — seo-programmatic-architecture

## Appropriate request
Task: create a reliable category URL system for a catalog.

## Near-miss request
Not this task: write a one-off editorial article.

## Domain-specific procedure
Start from a table of unique entity IDs, data provenance, refresh cadence and content value. Define canonical/index policy, paging, sitemap partitions, thresholds for noindex, stale-page retirement and soft-404 prevention. Pilot a small cohort and compare crawl/usage signals; do not assume that volume improves rankings.

## Required output
URL conventions, dataset contracts, pilot sample, indexability checks and rollback.

Demonstrative scenario only. Do not claim this scenario has been executed by a model.
