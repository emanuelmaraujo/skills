# Worked scenario — web-3d-experience-builder

## Appropriate request
Task: build an optional 3D rotatable product viewer.

## Near-miss request (different skill)
Not this task: render a static product image.

## Concrete procedure
Plan normal HTML content and poster first; mount WebGL only when needed, preserve labels outside canvas, cap pixel ratio, provide unavailable WebGL, network failure and reduced-motion alternatives. Test scene teardown on route changes and preserve keyboard product details.

## Output acceptance
3D interaction, poster/fallback, asset license, load observations and tested/unavailable states.

## Evidence discipline
This example is instructional, not an executed run. Report PASS/FAIL/SKIP/BLOCKED based on actual tool access; do not fabricate benchmarks or screenshots.
