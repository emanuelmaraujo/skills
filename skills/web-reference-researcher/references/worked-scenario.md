# Worked scenario — web-reference-researcher

## Appropriate request
Task: find inspiration for a new product landing page.

## Near-miss request (different skill)
Not this task: implement the landing page directly.

## Concrete procedure
Build a 3-row comparison with source URL, visit date, layout notes, mobile pattern, motion pattern, confidence, reuse rights and one adopted idea. Tag technology claims as observations or hypotheses; never infer React or WebGL from appearance alone.

## Output acceptance
Reference matrix plus a brief naming the role of each source and risks.

## Evidence discipline
This example is instructional, not an executed run. Report PASS/FAIL/SKIP/BLOCKED based on actual tool access; do not fabricate benchmarks or screenshots.
