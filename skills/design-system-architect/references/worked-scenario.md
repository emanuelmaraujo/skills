# Worked scenario — design-system-architect

## Appropriate request
Task: standardize spacing and button variants across existing React screens.

## Near-miss request (different skill)
Not this task: invent a new visual brand without implementation.

## Concrete procedure
Read current theme/tokens. Propose semantic names such as color.action.primary, space.3 and type.body.md, map existing values and migrate one representative component. For each token, record light/dark contrast, state behavior, owner and affected usages. Verify a minimal before/after screenshot when tooling exists.

## Output acceptance
Token inventory, migration map, affected components and evidence or BLOCKED.

## Evidence discipline
This example is instructional, not an executed run. Report PASS/FAIL/SKIP/BLOCKED based on actual tool access; do not fabricate benchmarks or screenshots.
