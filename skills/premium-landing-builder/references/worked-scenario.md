# Worked scenario — premium-landing-builder

## Appropriate request
Task: build a SaaS pricing page with clear CTA.

## Near-miss request (different skill)
Not this task: investigate why an existing page has low conversion.

## Concrete procedure
Create a five-section page contract: hero (offer + primary CTA), supporting proof (only real), benefit evidence, objections/FAQ, final CTA. Specify mobile section order, CTA state, form failure, metadata and asset provenance. Deliver a working route, not a design-only mockup.

## Output acceptance
URL/route, actual changes, CTA tests, 390/768/1440 viewport evidence and known gaps.

## Evidence discipline
This example is instructional, not an executed run. Report PASS/FAIL/SKIP/BLOCKED based on actual tool access; do not fabricate benchmarks or screenshots.
