# Worked scenario — frontend-visual-qa

## Appropriate request
Task: compare checkout page before and after a CSS change.

## Near-miss request (different skill)
Not this task: review database migrations or backend API logic.

## Concrete procedure
Record route, base and head commit, browser and viewport. At 390×844, 768×1024 and 1440×900 capture same states (default, error, modal and long text) if browser tools exist. For each mismatch report screenshot identifier, expected/actual, viewport, severity and exact reproduction. If browser inaccessible, mark BLOCKED rather than inventing images.

## Output acceptance
Visual report with screen/evidence references and fail/block list.

## Evidence discipline
This example is instructional, not an executed run. Report PASS/FAIL/SKIP/BLOCKED based on actual tool access; do not fabricate benchmarks or screenshots.
