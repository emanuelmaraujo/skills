# Worked scenario — engineering-independent-review

## Appropriate request
Task: inspect a checkout PR against issue requirements and repository rules.

## Near-miss request
Not this task: implement a new checkout flow from scratch.

## Domain-specific procedure
Pin merge-base, HEAD, originating issue and documented standards. Independently list behavioral/spec findings and maintainability/security findings; each must have a file+line, concrete impact and severity. Avoid approving based on style nits and report when the spec or tests are unavailable.

## Required output
Two-axis review report with reproduction, severity, evidence and explicit missing spec.

Demonstrative scenario only. Do not claim this scenario has been executed by a model.
