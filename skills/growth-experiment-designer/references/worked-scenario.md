# Worked scenario — growth-experiment-designer

## Appropriate request
Task: determine whether CTA A beats CTA B with limited traffic.

## Near-miss request
Not this task: list visual problems in a landing page.

## Domain-specific procedure
Pre-register null/alternative hypothesis, target population, assignment unit, sample ratio, baseline conversion, minimum detectable effect, power/confidence assumptions and stopping rule. Validate exposure event and variant consistency, sample-ratio mismatch and guardrails. Refuse to claim superiority if sample is insufficient.

## Required output
Experiment spec, metrics and assumptions, data-quality checks and explicit no-decision outcome where necessary.

Demonstrative scenario only. Do not claim this scenario has been executed by a model.
