# Worked scenario — web-motion-engineer

## Appropriate request
Task: improve a modal transition without breaking focus.

## Near-miss request (different skill)
Not this task: export a 30-second explainer MP4.

## Concrete procedure
Define motion table: element, trigger, from/to, duration, easing, cancellation, cleanup and reduced-motion alternative. Choose CSS for two-state transitions and a timeline library only for choreographed interactions. Ensure focus and navigation still work without animations; document mobile CPU observations if measured.

## Output acceptance
Animation table, reduced-motion behavior, teardown plan, measured or unmeasured test state.

## Evidence discipline
This example is instructional, not an executed run. Report PASS/FAIL/SKIP/BLOCKED based on actual tool access; do not fabricate benchmarks or screenshots.
